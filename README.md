# MyTraining — 筋トレ記録アプリ（PWA）

公開URL: https://mkpower-nanayon.github.io/mytraining/

BurnFit風のトレーニング記録アプリです。**ルーティンは無制限に保存でき、フォルダ分けできます。**

## 主な機能
- **カレンダー**：トレーニングした日を部位ごとの色ドットで表示。日付をタップするとその日の記録を表示。月間の回数・総ボリューム・時間
- **ワークアウト記録**：種目・セット（重量×回数）・前回記録の表示・セット完了チェック・経過時間・ボリュームの自動計算
  - 空欄のままチェックすると前回の値が自動で入ります
  - 休憩タイマー（セット完了で自動スタート、±10秒、スキップ、終了時に音とバイブ）
  - 最小化して他の画面を見ながら継続できます
  - 完了時にサマリーと自己ベスト更新（最大重量／推定1RM）を表示
  - ルーティンから開始した場合、今回の内容でルーティンを更新するか選べます
- **ルーティン（無制限）**：フォルダの作成・名前変更・並び替え・削除、ルーティンの作成・編集・複製・フォルダ間の移動・並び替え、検索
- **過去の記録の追加・編集**、記録からルーティンへの保存、「もう一度行う」
- **統計**：週別ボリューム、過去30日の部位別セット数、種目ごとの推定1RM／最大重量／ボリュームの推移と履歴、体重・体脂肪の記録とグラフ
- **種目ライブラリ**：約70種目を最初から登録済み。自分で追加・編集もできます（重量×回数／回数のみ／時間（秒）／有酸素（分・km））
- **設定**：kg/lb、休憩時間の初期値、サウンド・バイブ、JSONでのバックアップと復元

## 起動方法（PC）
```
node server.js
```
起動したら http://localhost:8080 を開きます。

## スマホで使う
データは各端末のブラウザの中に保存されます（サーバーには送信しません）。

1. **おすすめ**：このフォルダを GitHub Pages や Netlify などの HTTPS ホスティングに置き、スマホのブラウザで開きます。
   - iPhone：Safari → 共有 → 「ホーム画面に追加」
   - Android：Chrome → メニュー → 「アプリをインストール」
   - こうするとアプリのように全画面で動き、オフラインでも使えます。
2. **お試し**：PCで `node server.js` を実行し、同じWi‑Fiにつないだスマホから、表示された `http://192.168.x.x:8080` を開きます（この方法ではオフラインでは使えません）。

> 機種変更やブラウザのデータ削除に備えて、ときどき「設定 → バックアップを書き出す」でバックアップを保存してください。
